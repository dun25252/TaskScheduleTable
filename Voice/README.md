# Voice assets

実行時は配布ZIPの `Voice` フォルダーに以下のWAVファイルを配置します。

- 予定表が起動しました.wav
- 新規作成が完了しました.wav
- URLを作成しました.wav
- URLを変更しました.wav
- URLを削除しました.wav
- URLを無効にしました.wav
- 詳細を作成しました.wav
- 詳細を変更しました.wav
- 詳細を削除しました.wav
- 期限が近いタスクがあります.wav
- 予定が近いものがあります.wav
- タスクを変更しました.wav
- 予定を変更しました.wav
- タスクを削除しました.wav
- 予定を削除しました.wav
- 期限を変更しました.wav
- 編集を完了しました.wav
- エラーが発生しました。.wav

WAV本体は実行時資産として配布ZIPに同梱し、このリポジトリではファイル名と利用条件のみ管理します。
