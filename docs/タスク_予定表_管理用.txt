[DESCRIPTION]
デスクトップ上へ常駐表示できる、タスクと予定を一体管理するGUIツール。
黒背景・緑文字・緑枠を基本デザインとし、タスク/予定の追加・編集・削除、期限、詳細、URL、期限接近表示、音声通知、ウィンドウ位置/サイズ記憶、Windows自動起動、操作/エラーログを備える。

[FEATURES]
・デスクトップ上に表示する黒背景/緑文字/緑枠のGUI。
・初期サイズは約5件を見渡せる 760×390 相当。8方向ドラッグで連続変更でき、v1.5では最小約430×250まで縮小可能。
・タスク/予定が表示領域を超えた場合、右側の縦スクロールバーとマウスホイールで縦スクロール可能。横スクロールは禁止。
・「追加」「編集」「削除」をメイン画面から実行可能。
・編集は「編集」ボタン→対象行選択→所有ポップアップ画面で行い、編集画面はメイン画面より手前に維持。
・新規作成/編集項目: 種別（タスク/予定）、タイトル、詳細、URL、期限。
・URLと期限は有効/無効を選択可能。
・URLマークを各行の左側に配置。クリック時は同一URLポップアップ内で「URLを開く」「URLを挿入/変更」「URLをなしに設定する」「URLを削除」を実行可能。
・「URLをなしに設定」はURL文字列を保持したまま無効化。「URLを削除」はURL文字列自体を削除。
・期限なしは「期限なし」と表示。
・期限ありは期限まで14日以内で文字色を緑から赤へ連続変化。期限当日/期限超過は赤。
・期限7日前/3日前に通知。タスクは「期限が近いタスクがあります」、予定は「予定が近いものがあります」を再生。同一タスク・同一判定日は1回のみ。
・文字サイズは8.0～30.0ptを0.5pt単位で連続調整。「文字を大きくする」「文字を小さくする」および Ctrl+マウスホイールに対応。
・小型ウィンドウではタイトル行/一覧ヘッダー/下部ステータス行の高さ、左操作列幅、ボタン高/余白、URL/期限列幅、タイトルバー操作部を自動再計算し、文字切れ・重なりを防止。
・小さい高さでは左操作欄を内部縦スクロール可能にし、主要操作が画面外へ消えないよう維持。・各タスク名は1行表示。現在の表示幅に合わせて個別フォントを自動縮小し、最終的に省略表示して画面外へのはみ出しを防止。
・位置固定ON/OFF。ON時は通常ドラッグ移動を抑止するが、8方向からのウィンドウリサイズは許可。外部操作で意図せず位置が変化した場合は固定位置へ戻す。
・最前面表示ON/OFF。設定状態を次回起動時に復元。
・ウィンドウ位置、幅、高さ、文字サイズ、位置固定、最前面状態を保存し次回起動時に復元。
・保存位置が現在の仮想デスクトップ表示領域外の場合は可視位置へ自動補正。
・Windows起動時の自動起動をユーザーの Startup フォルダーへショートカットとして自動登録。管理者権限不要。
・アプリ起動時は一時的に前面表示し、その後は保存済みの最前面設定へ戻す。
・二重起動防止。
・操作ログを Log/タスク_予定表_Log_YYYYMMDD.txt に保存。
・例外/異常ログを Log/Error/タスク_予定表_Log_Error_YYYYMMDD_HHMMSS_mmm.txt に保存。
・GUIハートビートを別スレッドで監視し、5秒以上の応答停止をフリーズ疑いとしてErrorログ化。
・タスク/設定/通知状態の正本は %LOCALAPPDATA%\\TaskScheduleTable\\Data のJSONに保存。配布フォルダーの Data にもミラーし、保存前バックアップと一時ファイル方式を使用。
・詳細が設定されているタスク名へマウスを合わせると詳細を黒/緑のツールチップで確認可能。
・指定された全18種のテトボイスを Voice フォルダーから再生。

[SPECIFICATIONS]
・対象OS: Windows 11 x64を主対象。Windows PowerShell 5.1 / .NET Framework WPFが利用可能なWindows x64環境。
・実行方式: タスク_予定表.exe は5KB級のネイティブWin64ランチャー。KERNEL32.dll / USER32.dll のみを直接使用し、VC++ランタイム等の追加導入は不要。
・ランチャーは同一フォルダーの TaskScheduleTableBootstrap.ps1 を Windows PowerShell 5.1（-STA / -ExecutionPolicy Bypass / CREATE_NO_WINDOW）で起動する。
・BootstrapはASCIIファイル名固定とし、ZIP展開時の日本語ファイル名文字化けが起きても起動経路が壊れにくい構成。
・Bootstrapから TaskScheduleTable.ps1 を起動し、メインスクリプトの構文/初期化エラーも Log/Error へ記録する。
・Windows PowerShell起動時の -NonInteractive はv1.1で廃止し、GUI/WPF初期化への不要な制約を避ける。
・GUI: WPF。ProcessRenderMode=SoftwareOnly を指定し、アプリ描画でGPUを使用しない。
・ネットワーク: アプリ本体からWi-Fi/LAN/HTTP通信は一切行わない。URLを「開く」操作時のみ既定ブラウザーへURL文字列を渡し、通信処理はブラウザー側へ委譲する。
・CPU/RAM: GUI処理、期限判定、ログ処理、JSON処理、音声制御はCPU/RAMで実行。
・ストレージ: 要件上必須の永続化/ログ/音声読込のためローカルストレージのみ使用。タスク/設定の正本は %LOCALAPPDATA%\\TaskScheduleTable\\Data、Log/Voiceはアプリフォルダー内を使用。
・初期ウィンドウ: 760×390。v1.5の最小サイズは約430×250を基準とし、狭い幅/高さではコンパクトレイアウトへ自動切替。
・タスクデータ正本: %LOCALAPPDATA%\\TaskScheduleTable\\Data\\tasks.json。配布フォルダー Data/tasks.json にもミラー。
・表示設定正本: %LOCALAPPDATA%\\TaskScheduleTable\\Data\\settings.json。配布フォルダー Data/settings.json にもミラー。
・期限通知済み管理正本: %LOCALAPPDATA%\\TaskScheduleTable\\Data\\notifications.json。配布フォルダー Data/notifications.json にもミラー。
・自動起動: %APPDATA%\\Microsoft\\Windows\\Start Menu\\Programs\\Startup\\タスク_予定表.lnk。v1.1以前のRunキーは重複防止のため削除。
・ボイス: Voice/*.wav。ユーザー支給WAVをそのまま使用。v1.5時点で18種。
・ボイスキュー: WPF MediaPlayerで1本ずつ順次再生し、同時再生による重なりを防止。
・URL: http/httpsのみ。スキーム省略時は https:// を補完。
・期限入力: MM/DD または YYYY/MM/DD。MM/DDは「次に到来する同月日」として保存し、今日より前の月日は翌年扱い。YYYY/MM/DDは指定年をそのまま使用。
・期限表示: MM / DD。
・期限色: 14日以上=緑、14日未満～当日で緑→赤を線形補間、当日/超過=赤。
・期限ボイス: 7日前と3日前。アプリ起動時および30分ごとに確認。
・ログ: UTF-8。
・タスク/設定保存: UTF-8 JSON。更新前の .bak を保持。

[v1.5] DATE=2026-10-03
