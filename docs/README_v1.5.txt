タスク_予定表 v1.5 検証メモ
更新日: 2026-10-03

【v1.5 修正】
・小さいウィンドウ＋大きい文字サイズで、下部ステータス文字が行高不足により途中で隠れる問題を修正。
・タイトル行、一覧ヘッダー行、下部ステータス行の高さを現在の文字サイズから自動計算するよう変更。
・従来の最小520×320基準を見直し、最小約430×250まで縮小可能にした。
・小さい幅では左操作列、URL列、期限列、タイトルバー操作部を自動的にコンパクト化。
・小さい幅では「位置固定/最前面」を「固定/前面」、「文字を大きく/小さく」を「文字＋/文字－」へ切り替え、操作内容を保ったまま横幅を削減。
・小さい高さでは操作ボタンの高さ/余白を自動縮小し、補助表示「Ctrl + ホイールでも変更」を非表示化。
・高さがさらに不足する場合でも操作項目を失わないよう、左操作欄を縦スクロール可能にした。
・タスク一覧の行高を適正化し、小型ウィンドウでも表示件数を確保。
・ウィンドウサイズ変更中はレイアウト再計算を即時反映し、タスク行の再生成は短時間のデバウンス後に行うことで負荷を抑制。

【継続仕様】
・MM/DD期限は次に到来する日付として扱う。
・8方向リサイズ、位置固定ONでもリサイズ可能。
・既存18種VOICEを維持。
・タスク/設定の正本は %LOCALAPPDATA%\TaskScheduleTable\Data のため、v1.4からv1.5へ更新しても入力済み内容を継続利用する。
