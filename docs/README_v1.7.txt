タスク_予定表 v1.7 検証メモ
更新日: 2026-10-03

【v1.7 修正】
・v1.6のZIP内ファイル名が文字コード変換され、フォルダー名・EXE名・VOICE名などが文字化けする問題を修正。
・ZIPをUTF-8ファイル名フラグ付きで再構築し、Windows Explorerで日本語名をそのまま展開できるように変更。
・自動起動登録時にEXE名が旧版の文字化け等で変化していても、配布フォルダー直下のEXE実体を再探索して登録できるように修正。
・メインウィンドウのAllowsTransparencyを無効化し、ClearTypeを有効化。透明ウィンドウ由来の文字のにじみ・つぶれを抑制。
・8方向リサイズ用Thumbへ完全透明の専用ControlTemplateを適用し、Windows既定テーマが描画していた白い帯を除去。
・小型表示時の最小サイズを約380×220へ拡張し、450px未満では超コンパクトレイアウトへ切替。
・小型時はタイトルバー操作ボタン、左操作列、URL/期限列、行高、余白を追加で縮小。
・タスク名の自動縮小処理を改善し、レイアウト確定後に幅を再測定。最小5.5ptまで縮小して1行表示を優先。
・リサイズ用の再描画タイマーがRender-Tasksを再度予約し続けるループを修正。連続再描画によるCPU負荷と表示不安定を抑制。
・高さが小さい場合はタスク行高をさらに圧縮し、下端で文字が途中まで切れた行が出にくいよう改善。

【エラーログ反映】
・v1.6で確認された「Windows自動起動登録対象のEXEが見つかりません」は、ZIPの日本語ファイル名文字化けにより実ファイル名と想定名が一致しなかったことが原因。
・v1.7では配布ZIPの文字コードと自動起動EXE解決処理の両方を修正。
