# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## ダウンロード

`download/TaskScheduleTable_v2.2_READY.zip`

ZIPを展開して `タスク_予定表.exe` を起動するだけです。

## 主な機能

- タスク / 予定の追加、編集
- 各行のチェックボックスで完了 / 未完了
- 各行の × から完全削除
- 左側の削除モードは廃止
- 通常は期限・開始日時が近い順
- 完了済みは期限順では下へ移動
- ▲▼で手動順へ切替えて並び替え可能
- 「並び: 期限順 / 手動」で表示方式を切替
- 文字サイズ 8～30pt
- 詳細、URL
- 開始日・開始時刻・終了日・終了時刻
- 同日時間指定（例: 17:00 ～ 24:00）
- 日をまたぐ予定（例: 11/1 10:00 ～ 11/5 12:00）
- VOICE通知 / VOICE音量 0～100%
- 背景画像 / 透明度
- 文字背景の濃さ
- 文字・枠の色 / 背景色変更
- 新規作成・編集画面にも現在のテーマを継承
- Windows起動時に自動起動
