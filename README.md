# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## 新規インストール

`download/TaskScheduleTable_v2.6_READY.zip`

ZIPを展開して `タスク_予定表.exe` を起動します。

## 旧バージョンから更新

`download/TaskScheduleTable_Update_to_v2.6.zip`

更新ZIPを展開し、`タスク_予定表_Updater.exe` を起動してください。

- 旧版EXEを自動検出
- 見つからない場合は「参照...」から選択
- 更新前EXEを自動バックアップ
- 本体EXE・VOICE・アイコンを更新
- タスク、日時、完了状態、背景、色、VOICE音量などのユーザーデータは削除しません

## v2.6

- CMD依存の更新方式を廃止
- C# / WPFのGUIアップデーターを追加
- 更新先が自動検出できない場合も手動選択可能
- 更新前バックアップを日時別フォルダへ保存
- ドット絵アイコン入りの本体EXEへ更新
