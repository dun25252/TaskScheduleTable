# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## 新規インストール

`download/TaskScheduleTable_v2.5_READY.zip`

ZIPを展開して `タスク_予定表.exe` を起動します。

## 旧バージョンから更新

`download/TaskScheduleTable_Update_to_v2.5.zip`

1. 更新ZIPを旧バージョンのフォルダ内へ展開
2. `Update_to_v2.5.cmd` を実行
3. 旧EXEを `Backup_PreUpdate` へバックアップ
4. 本体EXE・VOICE・アイコンをv2.5へ更新
5. 更新後のアプリを自動起動

タスク、日時、完了状態、背景、色、VOICE音量などのユーザーデータは
`%LOCALAPPDATA%\TaskScheduleTable` に保存されているため更新では削除しません。

## v2.5

- ドット絵のカレンダー＋チェックアイコンをEXEへ埋め込み
- Windows Explorer / タスクバー / ショートカットで使用
- 通常版ZIPへ `TaskScheduleTable.ico` を同梱
- 更新版ZIPにも同じアイコン入りEXEとICOを同梱
- v2.4のアップデーター機能を維持
