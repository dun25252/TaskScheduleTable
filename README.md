# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## 配布版 v1.1

新規インストール:

`download/TaskScheduleTable_v1.1_RELEASE.zip`

旧バージョンから更新:

`download/TaskScheduleTable_Update_to_v1.1.zip`

更新ZIPを展開して `タスク_予定表_Updater.exe` を起動し、
現在使用中の `タスク_予定表.exe` を選択して更新します。

## 主な機能

- タスク / 予定の追加・編集
- 日付、時刻、期間指定
- 日付をまたぐ予定
- 完了チェック
- 期限が近い順の自動並び
- 手動並び替え
- 行ごとの完全削除
- 2段カード表示
- 文字サイズ 8～48pt
- URL
- 背景画像 / 透明度
- 文字背景の濃さ
- 文字・枠・背景色変更
- VOICE通知 / 音量調整
- Windows自動起動
- ドット絵アイコン

## バージョン方針

配布向けの公開バージョンは v1.1 です。
開発履歴 v2.7 は `Ver.2.7` ブランチに保存しています。
