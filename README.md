# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## ダウンロード

`download/TaskScheduleTable_v2.3_READY.zip`

ZIPを展開して `タスク_予定表.exe` を起動するだけです。

## v2.3

狭いウィンドウでも予定名が潰れにくいよう、一覧レイアウトを整理しました。

- 常時表示: 完了 / URL / 日時 / 予定名・タスク名
- 順番変更と完全削除は各行の「…」メニューに収納
- タイトル領域を最優先で確保
- 狭い幅ではヘッダー名も短縮
- URLボタンを小型化
- 完了チェックボックスも縮小
- 期限が近い順はそのまま維持
- 「…」→ 上へ / 下へ で手動順へ切替可能
- 「…」→ 完全に削除 でその行だけ削除
- 文字サイズ変更は8～30ptで維持

v2.2以前のタスク・日時・完了・背景・色・VOICE音量設定を引き継ぎます。
