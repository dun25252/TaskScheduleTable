# タスク_予定表

Windows 11 のデスクトップ上に常駐表示する、タスク・予定管理GUIツールです。

- 現在バージョン: **v1.7**
- GUI: WPF / Windows PowerShell 5.1
- 起動ランチャー: Win64 ネイティブ EXE
- 基本デザイン: 黒背景 / 緑文字 / 緑枠
- タスク・予定の追加、編集、削除
- 詳細、URL、期限、期限なし
- 期限接近表示・音声通知
- 位置固定 / 最前面
- ウィンドウ位置・サイズ・文字サイズの保存
- Windows ログオン時の自動起動
- 操作ログ / エラーログ / フリーズ監視

## v1.7

v1.6で残っていた白い外周帯、文字のにじみ/つぶれ、日本語ファイル名の文字化け、自動起動EXE未検出をまとめて修正しました。

- メインWindowを不透明化しClearType文字描画へ変更
- 8方向リサイズThumbを完全透明の独自テンプレートへ変更
- 最小約380×220、450px未満の超コンパクト表示を追加
- タスク名をレイアウト確定後に再測定して個別縮小
- リサイズ時の再描画タイマー自己再予約ループを修正
- 自動起動対象EXEを実ファイルから再探索可能に変更
- 配布ZIPはUTF-8ファイル名フラグ付きで作成


## ソース構成

- `src/TaskScheduleTable.ps1` — GUI・データ管理・通知・音声制御
- `src/TaskScheduleTableBootstrap.ps1` — 起動前診断と初期化エラー捕捉
- `src/launcher.c` — Win64 起動ランチャー
- `docs/タスク_予定表_管理用.txt` — 正式な管理情報
- `docs/README_v1.7.txt` — v1.5 の変更内容
- `Voice/README.md` — 実行時に必要なVOICEファイル一覧

## データ

実行時データの正本は以下に保存されます。

`%LOCALAPPDATA%\TaskScheduleTable\Data`

個人のタスク内容、設定、ログ、バックアップはGit管理対象にしません。
