# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## ダウンロード

`download/TaskScheduleTable_v2.1_READY.zip`

ZIPを展開して `タスク_予定表.exe` を起動するだけです。

## 主な機能

- タスク / 予定の追加、編集、削除
- 完了マーク（削除せず完了 / 未完了を切替）
- 詳細、URL
- 開始日・開始時刻・終了日・終了時刻
- 同日時間指定（例: 17:00 ～ 24:00）
- 日をまたぐ予定（例: 11/1 10:00 ～ 11/5 12:00）
- 期限が近づくと文字色が警告色へ変化
- VOICE通知 / VOICE音量 0～100%
- 位置固定 / 最前面
- ウィンドウサイズ / 文字サイズ変更
- 背景画像 / 背景画像の透明度
- 文字背景の濃さ
- 文字・枠の色変更 / 背景色変更
- 新規作成・編集画面にも現在の色と背景画像を継承
- Windows起動時に自動起動
