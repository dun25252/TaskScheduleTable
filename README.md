# TaskScheduleTable

デスクトップに置いて使うタスク表です。

## 使うだけ

`builds/v1.8-dev/TaskScheduleTable_v1.8_win-x64.zip` を展開して
`タスク_予定表.exe` を起動してください。

.NET SDKは不要です。

## できること

- タスク / 予定の追加、編集、削除
- 期限、URL、詳細
- 期限が近いと色が変わる
- ボイス通知
- 位置固定 / 最前面
- サイズ、文字サイズ変更
- 背景画像
- 背景画像の透明度変更
- Windows起動時に自動起動

## 自分でビルドする場合

`BUILD_v1.8.cmd` を使用します。

.NET 8 SDKが必要です。
Runtimeだけではビルドできません。
