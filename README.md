# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## 新規インストール

`download/TaskScheduleTable_v2.7_READY.zip`

## 旧バージョンから更新

`download/TaskScheduleTable_Update_to_v2.7.zip`

ZIPを展開して `タスク_予定表_Updater.exe` を起動し、
旧版の `タスク_予定表.exe` を選択して更新します。

## v2.7

一覧の可読性を根本的に変更。

- 横1列の表形式を廃止
- 1行を2段カード表示へ変更
- 1段目: タスク / 予定名
- 2段目: 日時 + URL
- 日時は省略せず折り返して表示
- タイトルは指定した文字サイズのまま表示し、AutoFitで勝手に小さくしない
- 文字サイズ上限を30ptから48ptへ拡大
- 文字サイズに合わせて行の高さも自動拡大
- 狭いウィンドウでは左メニューをさらに細くして一覧へ幅を優先
- 背景画像使用時も各タスク行の背景は最低72%の濃さを確保
- 期限順、完了チェック、手動並び、完全削除は維持

v2.6以前のタスク・設定データをそのまま使用できます。
