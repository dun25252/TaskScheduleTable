# TaskScheduleTable

デスクトップに置いて使うタスク・予定表です。

## ダウンロード

`download/TaskScheduleTable_v2.0_RELEASE.zip`

ZIPを展開して`download/TaskScheduleTable_v2.0_RELEASE`から `タスク_予定表.exe` を起動するだけです。

## 主な機能

- タスク / 予定の追加、編集、削除
- 詳細、URL、期限
- 期限が近づくと文字色が警告色へ変化
- VOICE通知
- VOICE音量 0～100%
- 位置固定 / 最前面
- ウィンドウサイズ / 文字サイズ変更
- 背景画像
- 背景画像の透明度
- 文字背景の濃さ
- 文字・枠の色変更
- 背景色変更
- Windows起動時に自動起動
