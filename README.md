# タスク_予定表

Windows 11 のデスクトップ上に常駐表示する、タスク・予定管理GUIツールです。

- 現在バージョン: **v1.5**
- GUI: WPF / Windows PowerShell 5.1
- 起動ランチャー: Win64 ネイティブ EXE
- 基本デザイン: 黒背景 / 緑文字 / 緑枠
- タスク・予定の追加、編集、削除
- 詳細、URL、期限、期限なし
- 期限接近表示・音声通知
- 位置固定 / 最前面
- ウィンドウ位置・サイズ・文字サイズの保存
- Windows ログオン時の自動起動
- 操作ログ / エラーログ / フリーズ監視

## v1.5

小さいウィンドウと大きい文字サイズを組み合わせた際に、下部ステータス文字が隠れる問題を修正しました。

- タイトル行、一覧ヘッダー行、下部ステータス行の高さを文字サイズから自動計算
- 最小ウィンドウサイズを約 430×250 まで縮小
- 幅が狭い場合は左操作列、URL/期限列、タイトルバー操作部を自動コンパクト化
- 高さが狭い場合はボタン高・余白を縮小
- 左操作欄を必要時のみ縦スクロール可能に変更
- タスク行高を小型表示向けに再調整
- 連続リサイズ時の再描画をデバウンスしてCPU負荷を抑制

## ソース構成

- `src/TaskScheduleTable.ps1` — GUI・データ管理・通知・音声制御
- `src/TaskScheduleTableBootstrap.ps1` — 起動前診断と初期化エラー捕捉
- `src/launcher.c` — Win64 起動ランチャー
- `docs/タスク_予定表_管理用.txt` — 正式な管理情報
- `docs/README_v1.5.txt` — v1.5 の変更内容
- `Voice/README.md` — 実行時に必要なVOICEファイル一覧

## データ

実行時データの正本は以下に保存されます。

`%LOCALAPPDATA%\TaskScheduleTable\Data`

個人のタスク内容、設定、ログ、バックアップはGit管理対象にしません。
