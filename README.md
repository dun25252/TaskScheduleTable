# TaskScheduleTable

デスクトップに置いて使うタスク表です。

## ダウンロード

`download/TaskScheduleTable_v1.9_READY.zip`

ZIPを展開して `タスク_予定表.exe` を起動するだけです。

.NET SDKのインストールやCMD操作は不要です。

## できること

- タスク / 予定の追加、編集、削除
- 期限、URL、詳細
- 期限が近いと色が変わる
- ボイス通知
- 位置固定 / 最前面
- サイズ、文字サイズ変更
- 背景画像
- 背景画像の透明度変更
- Windows起動時に自動起動
